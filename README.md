# unlearn-lvq
Unlearning sample effects of LVQ

Machine Unlearning for nearest prototype-based classifier models, starting with the Generalized Learning Vector Quantization (LVQ) model.
Requirement
### Requirements
Along with the environment files requirements.txt or pyenv_2026.yml please use SKLVQ by Dr. Rick van Veen for the quick demo and application on LVQ models.
